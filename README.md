### Featured: Kitchen Portal

</div>

<table align="center"><tr><td width="680">

**[kitchen-portal](https://github.com/Roman-Ghorbani/kitchen-portal)** · duty scheduling, late plates and menus for a 94-live-in fraternity house, running on a Raspberry Pi behind Cloudflare Tunnel.

- **Three users, three interfaces:** a phone app for brothers, a desktop console for the manager, a touch kiosk for the chefs
- **Hardened auth:** setup codes, escalating lockout, session versioning, scrypt + TOTP, revocable device pairing, signed calendar feeds, CSP, full audit log
- **Operated, not just built:** encrypted verified backups with a restore drill, systemd units, and a handbook for the next manager
- **Tested:** 208 unit and integration tests plus a browser end-to-end suite
